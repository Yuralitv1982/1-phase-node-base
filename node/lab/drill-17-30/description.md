### Шаг 2: Начинаем пайплайн (Фильтрация мусора)

Внутри метода `calculateCommercialVolume` нам нужно взять входящий массив `rawArray` и применить к нему `.filter()`.

Внутри `.filter(row => { ... })` нам нужно применить **Guard Clause** (Ранний возврат).
Логика такая:

1. Если строка пустая — возвращаем `false` (выбрасываем).
2. Разбиваем строку по запятой: `const parts = row.split(',');`
3. Если длина массива `parts` не равна 3 — возвращаем `false` (выбрасываем битые строки).
4. В конце возвращаем `true` (оставляем нормальные строки).

### Шаг 3: Усложняем фильтр

Нам нужно в каждой строке сделать `row.split(',')`. Если полученный массив частей не равен 3 по длине — строка битая, её нужно отбросить (`return false`).

Попробуй переписать фильтр вот так:

```javascript
const resultArr = rawArray.filter((row) => {
    // Guard clause 1: empty string
    if (!row) return false;

    // Split string by comma
    const parts = row.split(',');

    // Guard clause 2: invalid columns count
    if (parts.length !== 3) return false;

    return true; // Keep valid rows
});

```

Внеси это изменение в свой класс. А следующим шагом мы применим `.map()`, чтобы отфильтровать только `COMMERCIAL` и достать числа из объема! Что у тебя получится?

### Шаг 4: Маппинг и Свертка

Массив `parts` после сплита хранит данные в таком порядке: `[marketCode, traderType, volume]`.
То есть:

* `parts[1]` — это тип трейдера (`'COMMERCIAL'` или `'NON-COMMERCIAL'`).
* `parts[2]` — это объем (строка, которую нужно превратить в число через `Number(...)` или `parseInt()`).

Попробуй дописать цепочку методов прямо после `.filter(...)`.

```javascript
    static calculateCommercialVolume(rawArray) {
        const totalVolume = rawArray
            .filter((row) => {
                if (!row) return false;
                const parts = row.split(',');
                if (parts.length !== 3) return false;
                return true;
            })
            // --- ADD MAP HERE ---
            .map((row) => {
                const [, traderType, volume] = row.split(','); // Destructuring array parts
                return {
                    type: traderType,
                    vol: Number(volume)
                };
            })
            // --- FILTER ONLY COMMERCIAL ---
            .filter((item) => item.type === 'COMMERCIAL')
            // --- REDUCE TO SUM ---
            .reduce((sum, item) => sum + item.vol, 0);

        return totalVolume;
    }

```
